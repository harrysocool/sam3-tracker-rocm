# SAM3 ROCm 0.3.0-rc1

This release candidate advances the source version from `v0.2.0-rc6` while
continuing to use the checksum-pinned ROCm 7.14 / MIGraphX 2.17 / ONNX Runtime
1.24.2 runtime bundle published for rc4. No runtime binary, checkpoint, ONNX,
or MXR artifact is bundled with the source release.

## Release scope

- 504px FP16 full-detection live inference on gfx1151.
- Original SAM3 tracker memory policy: S7/C4.
- Latest-frame scheduling with no N+1 GPU lookahead.
- Same-frame parallel detector/tracker tail and fixed DETR decoder enabled.
- Local artifact compilation under verified EC Performance mode.
- 1008px/P48 is not part of the validated rc1 release scope.

## Artifact reproducibility

- Memory-attention S1--S10 graphs compile in independent processes with full
  benchmarking; S8 uses generic tuning and the other slots use the
  attention-specific MLIR policy.
- Build provenance binds resumable output to the source revision, checkpoint,
  container image, EC mode, and shape parameters.
- Writable ORT prewarm completes before the final schema-2 artifact manifest is
  generated.
- The manifest records runtime and hardware context plus SHA256 for every
  generated artifact; canonical benchmarks verify the complete file set.

## Benchmark contract

The repository provides fixed `canonical-250` and `soak-1000` profiles. They
pin the input video hash, prompt, arrival cadence, warmup exclusion, original
S7/C4 policy, fixed decoder, and latest-frame scheduler. Custom timing flags
are not accepted by the canonical harness.

## Release status

The source version and one-command release-gate workflow are prepared, but the
gate and `dev` to `release/rc1` to `main` review must complete before the
`v0.3.0-rc1` tag is created. The gate records a clean build, strict smoke,
artifact checksums, mask regression, three 250-arrival runs, a 1000-arrival
soak, and DAVIS regression in one evidence directory.
