# SAM3 ROCm 0.2.0-rc5

This source release builds on `v0.2.0-rc4` and keeps its checksum-pinned ROCm
7.14 / MIGraphX 2.17 / ONNX Runtime 1.24.2 binary runtime. It updates inference
behavior, integration reporting, installation guidance, and repository
organization without publishing a new runtime binary bundle.

## Inference behavior

- Live and offline 504px entry points now share the optimized FP16 MIG defaults,
  fixed DETR decoder, same-frame parallel tail, standard SAM3 postprocessing,
  and a persistent five-object cap per prompt.
- Both CLIs accept multiple prompts; `--max-objects 0` means unlimited and
  `--max-frames 0` reads video input to EOF.
- Offline input storage is separated from ordered tracking history so identical
  frame sequences use the same streaming session semantics as `SAM3Live`, while
  retaining offline-only next-frame backbone prefetch.
- Offline video continues after an empty first-frame result and applies its
  output score threshold on every frame.

## Live and ROS integration

- The ROS-shaped example uses the same CLI object-limit contract as the demos.
- Integration statistics distinguish completed inference, published output,
  age rejection, and results suppressed by a detached generation.
- The integration guide now states the ROS dependencies and adapter work that
  remain application responsibilities, and treats detector execution as a
  necessary policy gate rather than proof that an area is free space.

## Setup and repository guidance

- Model weights remain an external prerequisite under the SAM License; the
  repository neither distributes nor downloads them.
- Quick-start, container mounts, offline usage, read-only validation, and
  performance measurement scopes have been reviewed for a first-time user.
- Legacy host setup, old MIGraphX patch instructions, historical profilers,
  probes, and debug scripts are separated from supported entry points.
- The machine-specific tracked dataset link is removed; DAVIS and SA-Co remain
  external regression inputs.

## Runtime dependency reuse

The following release dependencies are unchanged from rc4:

- MIGraphX archive release:
  `v2.17.0+sam3-fc1sink.20260908.1`
- MIGraphX archive SHA256:
  `ed1458c632eb2f0e2cab3c457aee93e39196cbb77d2180e47525e0009563dac1`
- ONNX Runtime wheel SHA256:
  `ef10e3e808e8805c26cc27f47572a53e385463f29d578e1ea2fe13d00e6f5ee0`
- ONNX Runtime asset location: the existing `v0.2.0-rc4` GitHub release.

The local runtime image and binary-cache names therefore retain their rc4
dependency identifier. No rc5 ORT wheel, Docker image, checkpoint, or compiled
SAM3 model bundle is published by this source release.

## Validation

- Repository-root test suite: 213 passed before release metadata preparation;
  the final release gate reruns this suite.
- Same-model Live/Offline replay matched masks, boxes, scores, IDs, and prompt
  ownership for a 30-frame multi-prompt capped run and a 50-frame uncapped EOF
  run.
- The 30-frame PyTorch-versus-MIG regression recorded mask IoU 0.994427 mean /
  0.992279 minimum. The outputs are not bit-exact.
- Supported-container full/hybrid smoke passed with the fixed decoder and
  parallel tail loaded. The final release gate repeats the strict smoke.
- The prior clean runtime assembly and empty-directory model build are inherited
  because the binary/runtime and model-build paths are unchanged from rc4.

These are correctness and release-readiness checks, not a new latency
benchmark. The historical service-time measurements remain reference
observations rather than a release deadline or a new 100 ms claim.
