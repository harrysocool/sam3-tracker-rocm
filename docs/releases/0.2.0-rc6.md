# SAM3 ROCm 0.2.0-rc6

This source release builds on `v0.2.0-rc5` and reuses the checksum-pinned
ROCm 7.14 / MIGraphX 2.17 / ONNX Runtime 1.24.2 runtime bundle from rc4.
No runtime binary, checkpoint, ONNX, or MXR artifact is published with rc6.

## Container launcher portability

- `docker/rocm714/run.sh` now passes the invoking host username as `USER` and
  `LOGNAME` when it runs the container under the host UID/GID. This allows
  Torch and Transformers to initialize their caches when that UID is not
  present in the image passwd database.
- For an absolute `model.safetensors` symlink, the launcher now bind-mounts
  the resolved file at the symlink's original target path. This supports
  multi-hop links whose final file has a different basename, including common
  checkpoint-cache layouts.
- A broken absolute weight symlink now fails before Docker starts.

## Validation

- A Docker integration test runs the wrapper as synthetic UID `424242`, which
  is absent from the image passwd database, with a multi-hop absolute weight
  symlink under strict read-only mode. It imports `Sam3VideoModel` and
  `AutoProcessor` and verifies the mounted weight bytes.
- The normal source suite and supported-container smoke remain release gates.
