# SAM3 ROCm 0.2.0-rc4

This is a license and release-metadata update over `v0.2.0-rc3`. Runtime code,
the ROCm 7.14/MIGraphX 2.17 stack, and model-generation behavior are unchanged.

## Licensing

- Project-authored source code and documentation are licensed under
  Apache-2.0.
- Required upstream attribution is recorded in `NOTICE`.
- SAM model metadata and tokenizer files under `model/sam3/` retain the
  separate SAM License.
- Model checkpoints, media, third-party dependencies, downloaded binaries,
  datasets, and generated ONNX/MXR artifacts are not relicensed.

## Runtime dependencies

- MIGraphX archive release:
  `v2.17.0+sam3-fc1sink.20260908.1`
- MIGraphX archive SHA256:
  `ed1458c632eb2f0e2cab3c457aee93e39196cbb77d2180e47525e0009563dac1`
- ONNX Runtime wheel SHA256:
  `ef10e3e808e8805c26cc27f47572a53e385463f29d578e1ea2fe13d00e6f5ee0`

As with rc3, the release uploads only the ONNX Runtime wheel. MIGraphX remains
hosted in the AMDMIGraphX release; no Docker image, checkpoint, or compiled
model bundle is published.

## Validation inheritance

The runtime binaries are byte-identical to rc3. The rc3 clean validation
remains applicable: public dependency download, no-cache Docker assembly,
empty-directory 504px model generation, full/hybrid 12-frame smoke, 30-frame
PT-vs-MIG mask regression, and the 123-test source suite all passed. RC4 adds
license-scope tests plus a fresh public-download/provider smoke.
