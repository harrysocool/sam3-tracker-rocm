# SAM3 ROCm 0.2.0-rc3

This candidate restores the first release's delivery model with the current
ROCm 7.14 / MIGraphX 2.17 stack.

## Distribution

The runtime uses two separately hosted, checksum-pinned dependencies:

- [`migraphx-2.17.0-dev-9f1a138-sam3-fc1sink-rocm7.14-gfx1151-cp312.tar.gz`](https://github.com/harrysocool/AMDMIGraphX/releases/tag/v2.17.0%2Bsam3-fc1sink.20260908.1)
  is published from the `harrysocool/AMDMIGraphX` release and pinned by SHA256
  `ed1458c632eb2f0e2cab3c457aee93e39196cbb77d2180e47525e0009563dac1`.
- `onnxruntime_migraphx-1.24.2-cp312-cp312-linux_x86_64.whl` remains a SAM3
  release asset.

ROCm and gfx1151 PyTorch packages are downloaded from AMD. The Dockerfile only
installs precompiled packages; it contains no runtime source build. The
checkpoint remains a separate licensed download.

No complete Docker image and no compiled SAM3 model bundle are required release
assets. Users run `./setup.sh --runtime`, then `./setup.sh --models CHECKPOINT`
to generate their 504px ONNX/MXR artifacts locally.

The model build includes the environment-gated FC1-sink compiler library,
S1–S10 memory graphs, and a locally checksummed fixed DETR decoder. The clean
runner repeats image assembly, model generation, cache prewarm, and full/hybrid
smoke from an empty output directory.

The SAM3 release does not duplicate the MIGraphX archive; `build.sh` downloads
it from the pinned AMDMIGraphX release and verifies its SHA256 before assembly.
